# YMLAS

YMLAS (Ying Monitoring Logging Alert System) is a Flask-based infrastructure monitoring platform.

## Features

- Real-time CPU monitoring
- Memory monitoring
- Disk monitoring
- Log management
- Alerting framework
- Deployment tracking (planned)
- CI/CD integration (planned)

## Tech Stack

- Python
- Flask
- JavaScript
- Chart.js
- HTML/CSS
- Docker (planned)
- GitHub Actions (planned)
- AWS EC2 (planned)

## Run

```bash
pip install -r requirements.txt
python app.py
